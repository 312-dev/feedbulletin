## Background

`g80.bimmerpost.com` is the M3 G80/G82 subdomain of the Bimmer Network —
a multi-site vBulletin 4 install where each model generation (E90, F30, G80,
…) gets its own subdomain. They share forum software, theme, and markup, so
per-host seed profiles reuse the same selector shape.

## Why bundle it

BimmerPost is in the default-seed feeds. The Anthropic learner's one-shot
output on this theme has been observed to bind `div.usertitle` (rank) to all
three of Posts / Joined / Location, producing a "Second Lieutenant" repeat
in the author column. Bundling the hand-verified selectors with those
secondary fields explicitly null prevents that.
